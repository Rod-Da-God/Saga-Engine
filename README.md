# Saga Engine

Движок для оркестрации распределённых транзакций по паттерну **Saga**

## Проблематика

В распределённых системах операция часто затрагивает несколько независимых сервисов. Обычная транзакция БД здесь не работает, так как сервисы разные, единой транзакции быть не может.

Если один из шагов падает, систему нужно вернуть в согласованное состояние. Откатить уже выполненные шаги через компенсирующие действия.

Saga Engine должен решать эту проблему:
- описывает последовательность шагов и их компенсаций в YAML-конфигурации;
- выполняет шаги по очереди, вызывая внешние сервисы по HTTP(в не mvp мб и grpc);
- при ошибке автоматически запускает компенсации в обратном порядке;
- поддерживает retry с backoff для нестабильных вызовов;
- гарантирует идемпотентность через `Idempotency-Key`;
- переживает падение и рестарт движка. Cостояние хранится в БД, выполнение продолжается с точки остановки;
- предоставляет REST API для запуска, мониторинга и административного управления сагами.
